### 📂 Featured Projects

#### ⚡ [CodeSwitch](https://github.com/Tousifrahmananto/CodeSwitch)
A dual-engine code conversion application that translates source code between 5 languages instantly.
* **Tech:** Django, React 18, TypeScript, Groq/OpenAI, JWT (httpOnly), Monaco Editor.
* **Highlight:** Features an AI-first backend with automatic key rotation and a pure rule-based regex fallback engine, secured behind strict Content Security Policies.

#### 🎮 [AFK Productions Operations Tools](https://github.com/Tousifrahmananto/AFK_PRODUCTIONS)
A production-grade esports tournament management platform built for a 25+ member crew.
* **Tech:** MongoDB, Express, React, Node.js, Socket.IO, Tailwind CSS.
* **Highlight:** Implemented real-time bidirectional communication via WebSockets for live in-app notifications and an automated bracket generation engine (Single/Double Elimination).

#### 🗄️ [The Archive](https://the-archive-pdf.vercel.app/)
A secure, backend-agnostic PDF hosting platform with authenticated uploads and pluggable storage.
* **Tech:** Next.js 16 (App Router), React 19, Supabase Auth, Vercel Blob.
* **Highlight:** Protected REST APIs enforcing secure data access, user-scoped file isolation via bearer tokens, and in-browser document previews.
